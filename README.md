# Luxora - Haute Horlogerie & Luxury Timepieces

A production-grade luxury watch e-commerce website built with React 19, TypeScript, Tailwind CSS, and Framer Motion.

## Features
- **Haute Horlogerie Aesthetic**: Deep obsidian theme with champagne gold accents.
- **Interactive Complications**: Live flying tourbillon balance wheel oscillation, multi-angle inspection.
- **Product Showcase & Filters**: Filter by collection (Tourbillon, Chronograph, Celestial, Dress, Grand Complication) and metallurgy (Rose Gold, Titanium, Platinum, Steel, Carbon).
- **Interactive Curator Theater**: Dynamic masterpiece viewer with smooth Framer Motion transitions.
- **Bespoke Product Customizer**: Strap selection with live price adjustment and complimentary caseback engraving.
- **Wishlist System**: Persistent localStorage saved timepieces with quick move-to-bag.
- **Full-Featured Checkout**: Indian Rupee (INR) currency, UPI Instant, RuPay/Cards, RTGS Escrow, Web3 Crypto, and on-chain Cryptographic Certificate of Authenticity generation.
- **Order Lookup**: Track order fulfillment in real-time with digital provenance certificate.
- **VIP Concierge**: Private salon appointment bookings across Mumbai, New Delhi, Bengaluru, and Geneva.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the local development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```
